# Piece: Pattern

## Owner
- **Project:** Press
- **Process:** [Stress](process_stress.md)

## Place
[The Room After](place_the_room_after.md). Forms there. Returns from there faster each time.

## Load Bearing
Remove it and every [Gap](piece_gap.md) is met fresh.
No route is cheaper than another.
The family has no shape -- only events.
The [Cost](piece_cost.md) accumulates but teaches nothing.

## Apparent
A route that fires before the choice is made.
Not visible as a pattern to the one running it.
Visible in the repetition: the same exit, the same silence,
the same raised voice, the same smile that arrives too quickly.
The body recognises the [Signal](piece_signal.md) and moves
before the mind has named what it recognised.

## Yearbook
Documented in HPA axis habituation research: repeated stress exposure
reduces the threshold for the same response.
The route that ran once runs cheaper next time.
What was adaptation becomes automaticity.
In families it transmits: the child's Pattern
is partly the parent's Pattern
learned before the child had language for what they were learning.
In Press it is what makes the family a system
rather than five people in the same house.
